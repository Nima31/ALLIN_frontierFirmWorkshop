# The Frontier Firm Experience

## Putting AI Agents to Work

This repository contains the hands-on lab for the **ALL IN 2026** workshop. In
the lab, participants redesign a real workflow for effective human–agent
collaboration, prototype an agent, and evaluate it before deciding whether it
is ready to deploy.

## Get started

Open the [workshop lab](docs/workshop.md) and follow it from **Lab overview**.
The lab is designed for pairs or small groups and takes approximately 90
minutes.

### What you need

- A laptop with internet access
- Access to the AI agent environment provided by the facilitator
- A non-sensitive workflow or the sample scenario in the lab

Do not enter confidential, personal, customer, or production data into the
workshop environment.
